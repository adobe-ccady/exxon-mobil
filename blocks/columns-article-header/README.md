# columns-article-header

Custom **columns** block. Purpose: article-header.

## Authoring (Document Authoring)

Model: `columns`

Single block table. Content: one row, two cells.

- Cell 1 (metadata rail): tag link paragraph, content type paragraph, date paragraph. All optional.
- Cell 2: H1 title, then an intro paragraph (optional).

Share and print buttons are added by the block code and are not authored.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
